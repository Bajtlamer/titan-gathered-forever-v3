# Titan Gathered Forever: Discovery 0.1.8

Update from 0.1.7. This text is the changelog for the release page.

## Changed

- The module is renamed from Titan Gathered Discovery to **Titan Gathered Forever: Discovery**, the same form as the other modules. The new name is in the AddOns list, the window title, the Titan Panel plugin, the minimap button menu, the guide and the chat messages. The folder (`TitanGatheredForever_Discovery`), the commands (`/tgfd`) and the collected data stay the same, and so does the place of the Titan Panel plugin.

## Upgrading

Install over the old folder. Data collected so far is kept.
