# Titan Gathered Discovery 0.1.6

Update from 0.1.5. This text is the changelog for the release page.

## Changed

- Titan Panel is optional. The module needs only the Titan Gathered Forever core (0.5.177 or newer to run without Titan Panel). With Titan Panel installed, the plugin "Titan Gathered Discovery" shows as before; without it, the window opens from the right click menu of the minimap button or with `/tgfd show`.

## Upgrading

Install over the old folder. Data collected so far is kept.
