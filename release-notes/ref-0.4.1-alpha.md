# Titan Gathered Forever v3 0.4.1-alpha

Historical versioned release notes. Subsequent development is recorded in [the unreleased changelog](ref-unreleased.md); the current source update does not republish these release assets.

Renamed the addon pack to Titan Gathered Forever v3. The core folder, optional module folders, matching manifests, dependencies, namespace, Titan broker identity, UI labels, development tooling and distributable filenames use the new identity.

Use the complete collection or the renamed shared core plus selected profession packages. Do not enable both generations together. Titan Panel remains a separate dependency.

Existing settings, inventory snapshots, spots and lifetime history can be preserved with the one-time SavedVariables migration described in README.md. The migration copies the original data and refuses to overwrite an existing destination. Close WoW before migrating. Enable the newly named Titan broker entry after installation.

This release changes identity and packaging; crafting/cooking operation counters and dataset export remain planned. Real-client validation of the renamed installation and migrated state is still required.
