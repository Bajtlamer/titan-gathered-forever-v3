# Titan Gathered Forever 0.5.172

Update from 0.5.171. This text is the changelog for the website and the release page. No new files were added: a plain reload is enough after updating.

## Fixed

- **No double question mark for a finished quest.** When the objectives of a quest were done, the game showed its own question mark at the turn-in and the addon's silver question mark stayed next to it. The addon pin now disappears as soon as the quest is ready to turn in, and comes back if the quest counts as open again (for example after an objective item is lost). The pin tooltip shows such a quest as Ready to turn in.

## Upgrading

Install over the old folders. Your saved data and settings are kept. The thirteen optional modules only carry the new version number: their catalogue data is unchanged.
