# Titan Gathered Forever: Auction Items

## Summary

Adds the optional Auction Items catalogue to Titan Gathered Forever for WoW Forever.

## Description

Extend Titan Gathered Forever with its optional Auction Items catalogue. This module supplies additional supported-item records to the shared core, alongside whichever profession catalogues you choose to install.

### Features

- Register the supported additional-item catalogue with the shared core.
- Make those records available to the core's applicable item-use and inventory features.
- Manage the additional items separately from profession catalogues.

### Requirements and installation

Requires **WoW Forever 1.60.1**, **Titan Panel** and the **Titan Gathered Forever shared core**. Install `TitanGatheredForever_AuctionItems` in `Interface/AddOns/`, alongside `TitanGatheredForever` and Titan, then restart WoW.

### Getting started

Open the shared core's right-click menu and inspect **Additional items**. The module supplies catalogue records; auction scanning and pricing features are provided by the shared core when suitable client data is available.

This module shares the core's controls and saved history. Disabling a module retains the core's previously recorded statistics.

### Notes and limitations

The current additional-item catalogue is small and is still being expanded. It is not a complete inventory of auctionable items. Displayed market information, where available through the core, reflects recorded scan data and may become outdated.

### Reporting issues

Include the core and module versions, client build, affected item or recipe IDs, steps to reproduce and the expected result. For missing recipe uses, include the recipe name and relevant materials. A screenshot of the tooltip or profession window is useful.
