# Titan Gathered Forever: Tailoring

## Summary

Adds Tailoring materials and recipe data to Titan Gathered Forever, connecting cloth, thread and other reagents with their crafting uses in WoW Forever.

## Description

Extend Titan Gathered Forever with its Tailoring catalogue. Connect supported cloth, thread and other reagents with Tailoring recipes. The shared core uses these records in its supported tooltips, inventory views and profession features.

### Features

- Add the supported Tailoring material catalogue to the shared core.
- Provide profession-use relationships and the available recipe data for included items.
- Use the core's applicable inventory, browsing and personal reporting features with this catalogue enabled.

### Requirements and installation

Requires **WoW Forever 1.60.1**, **Titan Panel** and the **Titan Gathered Forever shared core**. Install `TitanGatheredForever_Tailoring` in `Interface/AddOns/`, alongside `TitanGatheredForever` and Titan, then restart WoW.

### Getting started

Open the shared core's right-click menu, choose **Professions** and enable **Tailoring**. Inspect a supported material tooltip to see its uses and inventory information. For crafting professions, open the profession window so the core can read available recipe details and learned status.

This module shares the core's controls and saved history. Disabling a module retains the core's previously recorded statistics.

### Notes and limitations

Catalogue coverage and live obtainability remain under verification. Recipe availability and crafting requirements depend on your character and the client. Personal history and source information depend on the core's recording settings and readable observations; earlier activity cannot be reconstructed.

### Reporting issues

Include the core and module versions, client build, affected item or recipe IDs, steps to reproduce and the expected result. For missing recipe uses, include the recipe name and relevant materials. A screenshot of the tooltip or profession window is useful.
