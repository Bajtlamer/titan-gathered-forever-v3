# Titan Gathered Forever v3 0.4.0-alpha

TGF v3 helps crafters understand material uses, current inventory, acquisition locations and personally observed results. This alpha introduces per-character lifetime acquisition totals and source-rate reports, with an optional combined view.

- Open `/tgf history` for obtained-item totals and `/tgf chances` for observed source rates with sample counts.
- Track fishing, mining/herbalism byproducts, skinning and supported ordinary material drops. Disenchanting groups results by known input item and creates no map spots.
- Control recording, professions, individual map materials and world/minimap visibility separately. Clear category spots without clearing lifetime statistics.
- Item and recipe-material tooltips include inventory, uses and recorded source evidence.

History begins with acquisitions recorded in this version. Old map observations cannot reconstruct earlier item quantities or drop rates. Percentages use complete observed loot samples and are not guaranteed server probabilities. Dedicated action counters, crafting/cooking statistics and dataset export remain planned.

Download the complete collection or the shared core plus selected profession ZIPs. Install Titan Panel separately. The clean release directory also contains downloads.json and SHA256SUMS for website distribution.

The automated suite passes. Real-client fishing/disenchant event timing, report layout and catalogue completeness remain alpha validation work.
